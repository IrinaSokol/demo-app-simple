# ProjectOps Admin (application code)

This repo is the **application under test**. Playwright automation lives in the sibling
repo `../demo-app-simple-e2e`.

When asked to write or change Playwright tests:

1. Read `../demo-app-simple-e2e/PLAYWRIGHT_AI_CONTRACT.md` first and follow it.
2. Write test code only in `../demo-app-simple-e2e`. Treat this repo as read-only.
3. Discover locators by reading `src/**` and `server/**` — never guess them.
